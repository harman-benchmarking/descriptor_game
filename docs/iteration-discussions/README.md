# Iteration Discussions

This folder collects design discussion notes before implementation.

## Naming Convention

Use:

```text
iteration-discussion-YYYY-MM-DD-short-topic.md
```

Examples:

- `iteration-discussion-2026-04-26-mvp-next-iteration.md`
- `iteration-discussion-2026-04-26-learn-true-listening-test.md`

Keep each document focused on one product/design decision. If a discussion becomes implementation work, create or update a separate implementation plan rather than mixing code tasks into the discussion note.
